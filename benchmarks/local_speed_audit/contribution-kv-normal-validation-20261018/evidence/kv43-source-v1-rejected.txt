## Blocking label mismatch

The fixed create command sets `vllm.scout.owner=stream-kv43-v1`. It does not set `vllm.scout.source` or `vllm.scout.variant`.

The same plan's `candidate.labels` expects owner `vllm-scout-background12-v2-20261018`. It also expects source `c8edf6d9cc476fd0f1bc8c318a6529966cd8eed9b9bf9c0a39dc324829d25b66` and variant `candidate`.

`run_once.identity()` requires every `candidate.labels` row in the created container. `run_once.admit()` builds the expected Docker Config from the same labels. A container created by the sealed command cannot satisfy those checks. The source generator replaced `background12-v1`, but the inherited owner label contains `background12-v2`.
