## Separate source boundary: reduce-scatter axes

The narrow question was whether the input and output axis moves are inverses for supported production calls. Both current base and CUDA `reduce_scatter` use `movedim(0, dim)` on entry and exit. Their group wrapper accepts a dimension in the tensor's rank range.

Own list-axis arithmetic identifies a discrepancy for rank3 last-axis inputs. With shape `(2,3,8)`, axis2 and world2, the modeled entry shape is `(3,8,2)` and the leading-axis divisibility assertion rejects it although axis2 is divisible. With `(2,4,8)`, the modeled returned shape is `(8,2,2)` instead of `(2,4,4)`. These are five scalar shape models, including three passing controls. They are not distributed, Torch or native tests.

This is exactly the old mechanism in closed issue #30546. Its five comments link the closed, unmerged #30610, head `04f98368481b6b74c7c0e8bce8ffd31476cacdb0`. That patch makes the same entry-axis correction. The issue-linked open-PR query is empty. Open #61138 and #61140, with exact heads/diffs retained, optimize dim0 in the same methods; they retain the old nonzero-axis expression. This is adjacent same-method work, not a claim that those PRs fix the rank3 case.

The saved complete lexical search is limited to literal `reduce_scatter(` and `tensor_model_parallel_reduce_scatter` in current `vllm/`. The named production callers found use axis0, DCP axis1, or Inkling's last axis. The DCP contract is rank3 `[B,H,D]`, but axis1 is an adjacent swap and the shape model passes. Inkling's NVIDIA model explicitly flattens hidden states to rank2 before its layers; its last-axis use is therefore not new rank3 proof. No supported production rank3 last-axis trigger was established. Dynamic aliases or external callers are not exhaustively excluded.

Decision: retain the old API source discrepancy as **rejected for this contribution batch**, with no supported new production trigger. Do not manufacture an artificial input regression or reopen the old report on this evidence alone. No native bug, crash, out-of-bounds access, model effect or performance result is claimed.
